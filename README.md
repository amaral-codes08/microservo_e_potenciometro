# microservo_e_potenciometro

A leitura do potenciômetro é realizada pelo pino A0;
O microservo é controlado através do pino 9;
O potenciômetro permite ajustar o servo entre 0° e 180°.

Materiais necessários:
Qtd	Componente
1	Placa Arduino UNO
1	Cabo USB
1	Protoboard
1	Microservo
1	Potenciômetro
—	Fios de jumper macho-macho
